# 올케어에듀 · 과학 학습현황

권일준 선생님반(고1·중3) **과학 주간테스트** 웹앱의 공개 화면과 코드입니다.

- 학생: 개인 링크에서 문항별 답(①~⑤)을 고르면 바로 채점 · 결과 리포트 · 같은 개념 반복 오답 경고 · 회차별/기간별 오답 시험지(인쇄 → PDF)
- 학부모: 점수 추이 · 보완 개념 · 선생님 리포트 (틀린 문항 번호는 보여 주지 않음)
- 강사: 반별 결과 · 문항별 정답률 · 개념별 약점 · 학생별 오답지 · 재응시 허용

## 구성

| 위치 | 하는 일 |
|---|---|
| `index.html` | 공개 화면(GitHub Pages). 학원 Apps Script 웹앱에서 화면을 받아 그립니다. |
| `apps-script/Code.gs` | Apps Script 웹앱 본체 (DB 시트 · 채점 · 화면). 학생 명단과 관리 키는 들어 있지 않습니다. |
| `tools/register_test.py` | 선생님이 보낸 주간테스트(HWP/PDF)에서 정답 · 문항 그림을 뽑아 등록 파일을 만듭니다. |

## 데이터 흐름

1. 주간테스트 파일(HWP + PDF) → 드라이브 「과학/날짜」 폴더
2. `register_test.py` → 「과학/00 학습현황/시험/{시험ID}.zip」 (정답 · 문항 그림 · 개념 태그)
3. 웹앱이 10분마다 폴더를 읽어 DB 시트에 반영
4. 학생은 수요일~토요일 개인 링크로 답 입력 (마감: 토요일 자정)
5. 일요일 00:05 리포트 작성 → 「00 학습현황/리포트/{시험ID}.json」 → 학생 · 학부모 · 강사 화면에 표시

문항 그림 · 정답은 저작권이 있는 시험지에서 나온 것이라 이 저장소에는 올리지 않고 학원 드라이브에만 둡니다.

## 운영 규칙

- 코드를 고친 뒤에는 **새 배포를 만들지 말고** [배포 관리] → 수정 → **새 버전** (학생 링크 주소 유지)
- `setup`은 처음 한 번만 실행
- 새 기능은 시험용 학생 링크로 먼저 확인
